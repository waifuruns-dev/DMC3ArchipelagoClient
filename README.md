## Devil May Cry 3 Archipelago Randomizer (waifu's fork)

This is a fork of [AshIndigo's DMC3 Archipelago Randomizer](https://github.com/AshIndigo/DMC3ArchipelagoClient),
made with his permission. **All of the randomizer is AshIndigo's work**; this fork adds a few fixes on top.

Changes in this fork:
- The second Artemis spawn (Mission 16, room 117, which appears if Artemis wasn't collected in Mission 6)
  now counts as the "Mission #6 - Artemis" check and gives its item.
- Receiving a level for the style you currently have equipped no longer crashes the game.

These changes were written with help from AI (Claude) and tested in game by waifu.
They are also offered back to the original repository.

The matching logic changes (secret mission requirements, abilities in logic, and the optional
"Out of Mission Checks" backtracking routes) are in the apworld fork:
https://github.com/waifuruns-dev/Archipelago/tree/dmc3-logic-fixes/worlds/dmc3

See APWorld setup document for installation instructions
https://github.com/AshIndigo/Archipelago/blob/dmc3-world/worlds/dmc3/docs/en_setup.md
